# Routes Contract

## Pages

- `/` (Landing)
  - Must render the featured episode hero (title, description, publish date, duration, cover art)
  - Must provide a play action for the featured episode
- `/episodes` (Episodes)
  - Must render a list of exactly 20 episodes from mocked data
  - Must provide a way to listen to a selected episode (inline or dedicated view)
- `/about` (About)
  - Must render show description content with semantic headings
- `/faq` (FAQ)
  - Must render questions/answers in a scannable, accessible format

## Navigation

Primary navigation must link to all pages and remain usable without JavaScript.
