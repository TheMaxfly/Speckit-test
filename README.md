# Sleek Static Podcast Website

This repository contains a Next.js app configured for static export, with mocked/embedded podcast data.

## Run locally

```bash
cd web
npm install
npm run dev
```

## Build static export

```bash
cd web
npm run build
```

Output: `web/out/`

## Preview static export

```bash
cd web
npm run preview
```

## Tests (E2E)

```bash
cd web
npm test
```

open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
